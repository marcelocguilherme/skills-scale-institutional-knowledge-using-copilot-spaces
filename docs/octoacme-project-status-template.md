# OctoAcme — Project Status Page Template

## Purpose
Provide a reusable template for a single-source-of-truth project status page. Copy this template into the project repository as `STATUS.md` (or into the project README) and keep it updated on a regular cadence.

## When to Use
- At project kickoff, create the status page from this template.
- Update at least weekly (or on each milestone), as agreed with stakeholders.
- Share the link in all stakeholder communications so everyone references the same source. See [Risk Management & Communication](octoacme-risks-and-communication.md) for update cadence guidance.
