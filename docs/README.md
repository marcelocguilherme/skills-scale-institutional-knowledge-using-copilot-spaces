# OctoAcme — Project Management Docs

This folder centralizes all project management process documentation used by OctoAcme. Use the guides below to understand how we initiate, plan, execute, and deliver projects — and to onboard quickly to our standard workflows.

## How to use these docs

- Start with the [Project Management Overview](octoacme-project-management-overview.md) for a high-level picture of OctoAcme's approach.
- Follow the lifecycle docs in order when starting or joining a project.
- Reference the [Roles & Personas](octoacme-roles-and-personas.md) guide to understand who does what.

## Core Roles & Personas

| Role | Responsibilities |
|---|---|
| **Project Manager (PM)** | Coordinates delivery, manages schedules, risks, and communications; facilitates key meetings |
| **Product Manager (PdM)** | Defines outcomes, prioritizes the backlog, and measures product success |
| **Developers** | Implement features, write tests, participate in code reviews and planning |
| **QA / Testing** | Validate quality and acceptance criteria before release |
| **Stakeholders** | Provide inputs, approvals, and strategic direction |

For detailed responsibilities and goals per role, see the [Roles & Personas guide](octoacme-roles-and-personas.md).
